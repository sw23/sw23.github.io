# Security Policy

## Supported versions

This repository is a static site served from `main`; fixes go there.

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/sw23/sw23.github.io/security/advisories/new)
(the **Report a vulnerability** button on the repository's Security tab)
rather than in a public issue.

Include what you found, how to reproduce it, and the impact you expect. Reports
are handled on a best-effort basis; you'll get a reply on the advisory once
it has been reviewed, and fixes are credited in the advisory unless you'd
rather stay anonymous.
